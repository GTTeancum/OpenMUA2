## Native REL recovery

First REL loader repair committed for the known MUA2 halfword relocation behavior:

- `R_PPC_ADDR16`, `R_PPC_ADDR16_LO`, `R_PPC_ADDR16_HI`, and `R_PPC_ADDR16_HA` now write at the relocation offset itself, not `offset + 2`.
- REL patch bounds now check the actual relocation field width instead of requiring every relocation to have four writable bytes.
- The top-level DolRecomp copy and the ModernGekko-pinned DolRecomp copy were updated together.
- Added a DolRecomp regression fixture proving an `ADDR16_LO` relocation with offset `2` patches the immediate halfword of the instruction word.
